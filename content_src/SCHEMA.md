# 期中複習 RPG：各科內容檔格式

每科一個檔案 `content_src/<id>.json`（UTF-8，無 BOM）。遊戲網站是**公開的**，題目和答案都會在瀏覽器裡看得到。

## 硬性規則
1. **不能放任何期中考題**（學生卷、教師卷、題目對照、給分檔裡的題目），也不能改寫到一看就知道是同一題，或洩漏期中考某一題的答案。
2. **不能放 `題庫.csv`、`_L4測驗/` 的題目**，也不能放任何標成 L4 的題目。
3. 只出期中範圍內、課堂真的教過的內容；教材沒提到的知識不要出題。
4. 不要捏造人名、機構、網址、數據來源。NPC 與吉祥物是原創角色，不要用任何遊戲、動漫角色名稱。
5. 語言照該課程 CLAUDE.md 的規則（國合班是 A2 中文：句子短、常用字，專有名詞可在括號附英文）。繁體中文、臺灣用語。

## 檔案格式
```json
{
  "id": "gchem",
  "title": "網站名稱，10 字內",
  "tagline": "一句話介紹，25 字內",
  "audience": "例如：大一普通化學",
  "scope": "W1–W3",
  "mascot": {"name": "吉祥物名", "description": "外觀一句話"},
  "center": {"name": "中央島名，8 字內", "description": "一句話：期中總複習島"},
  "islands": [
    {
      "name": "島名，8 字內",
      "group": "分類（海域），4 字內，全科 2–4 種",
      "week": "W1",
      "icon": "一個 emoji",
      "landmark": "從下面清單挑一個",
      "intro": "一句介紹，25 字內",
      "points": ["重點1（15 字內）", "重點2", "重點3"],
      "goal": "學習目標，一句話",
      "npc": {"name": "導師名，4 字內", "line": "打招呼一句話"},
      "helper": {"name": "島民名，5 字內"},
      "lessons": [
        {"title": "= points[0]", "text": "2–3 句重點說明", "example": "一個具體例子或算例"},
        {"title": "= points[1]", "text": "...", "example": "..."},
        {"title": "= points[2]", "text": "...", "example": "..."}
      ],
      "worksheet": ["開放題1", "開放題2", "開放題3"],
      "quiz": [
        {"prompt": "題目", "options": ["選項A", "選項B", "選項C", "選項D"], "answer": 0, "explanation": "1–2 句詳解，說明為什麼對、常見錯在哪"}
      ]
    }
  ]
}
```

- `islands`：4–8 座。一週一座；範圍少於 4 週時，把內容多的週拆成兩座。
- `quiz`：**每座島剛好 6 題**，四選一。遊戲每次隨機抽 3 題、選項會打亂，所以不要寫「以上皆是」「以上皆非」「A 和 B」這種依賴位置的選項。`answer` 是正確選項在 `options` 裡的索引。
- 誘答要合理、長度和正解差不多（不要讓最長的那個永遠是答案），最好每個誘答對應一個常見錯誤。
- 數值題請自己驗算，詳解寫出算式。
- `worksheet` 剛好 3 題，`lessons` 剛好 3 則，`points` 剛好 3 點。
- `landmark` 可選：`flask`（錐形瓶實驗桌）、`balance`（天平）、`oven`（烘箱／高溫爐）、`burette`（滴定架）、`molecule`（球棍分子模型）、`atom`（原子與軌道）、`helix`（雙螺旋）、`enzyme`（酵素與受質）、`book`（打開的書）、`scroll`（寫作書桌與卷軸）、`chart`（長條圖看板）、`food`（餐盤與食物）、`cup`（飲料杯）、`microscope`（顯微鏡）、`leaf`（大葉片／植物）。同一科盡量不重複。
