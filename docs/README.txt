期中複習島｜靜態網站

請用 HTTP 網站伺服器開啟 index.html，不能直接雙擊 HTML。
整個資料夾就是網站根目錄，沒有建置步驟，也不需要 API 金鑰。
請保持 js/、data/、vendor/、styles.css 的相對位置。

選科頁：index.html；遊戲頁：play.html?c=<科目代號>
各科重點、練習題、居民對話：data/<科目代號>.json（由上一層的 build.py 產生）
Three.js：0.160.0；授權文字：vendor/THREE-LICENSE.txt
幾何模型、角色與介面都是本專案用程式繪製的原創內容。

練習題是自編的，不是期中考題。本站不接 AI 服務，也不蒐集資料。
進度存在瀏覽器裡，請用接關碼或 JSON 備份。
